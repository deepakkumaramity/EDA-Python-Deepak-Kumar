# Exploratory Data Analysis (EDA) with Python
**Author:** Deepak Kumar

This project performs EDA on the Titanic dataset using Python, Pandas, Matplotlib, and Seaborn.  

## Features
- Data overview: head, info, describe
- Countplots and histograms with watermark
- Insights from dataset

## Folder Structure
- `data/` : Contains dataset
- `notebooks/` : Jupyter notebook version
- `scripts/` : Python scripts
- `images/` : Generated images with watermark

## How to Run
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run `python scripts/eda.py` to generate visualizations
4. Open `notebooks/EDA.ipynb` for interactive analysis
